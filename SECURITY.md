# Security and private reports

Maintainer: [Gopi krishna Gajam](https://github.com/gopikrishnagajam).

For a vulnerability, account incident, or sensitive privacy concern, use private
contact options listed on the maintainer's GitHub profile. If no suitable channel
is available, open an issue that only requests private security contact. Do not
publish exploit details, email addresses, cookies, passwords, sign-in codes,
database credentials, private records, or guest acknowledgment links.

Arrange a private channel before sending reproduction steps or sensitive logs.
Use synthetic accounts/data, describe impact and affected versions, and avoid
accessing other people's records. Testing against this public app is not an
authorization to scan, disrupt, exfiltrate, send bulk emails, or bypass controls.

Only the current development release is maintained. The public app is a testing
deployment with the operational limits listed in [Operations](docs/operations.md).
The MIT license does not grant access to hosted accounts, infrastructure, or data.

For non-sensitive bugs, ordinary repository issues are welcome. Data requests
follow the [Privacy notice](PRIVACY.md).
